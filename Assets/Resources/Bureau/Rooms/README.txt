Изображения каждой комнаты входят в архив «Комнаты_Бюро_для_Unity.zip».
Распакуйте архив и скопируйте папку Assets в КОРЕНЬ Unity-проекта.
Все остальные файлы и сцены сохраняйте. Ничего не заменяйте вручную.
PNG в этих папках импортируются как Texture Type = Default.

Бюро -> ОТДЕЛЫ -> открыть помещение за монеты.
Дело Никиты -> фотолаборатория.
Дело Марии -> архив.
Дело Веры -> мастерская.
Если монет не хватает, при переходе из дела можно выбрать временный
бесплатный пропуск: прохождение сюжета не блокируется.
